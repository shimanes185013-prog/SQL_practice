## 使用環境
# DBMS
- SQLite
- サーバーレスのデータベースシステムであり、簡易的なシステムに採用されている。
- サーバーの用意が必要ないため練習には最適であると思い使用した。

# DBクライアント
- DBbever
- データベースの閲覧専用ソフト。
- SQLiteのみではできない操作が可能になる
